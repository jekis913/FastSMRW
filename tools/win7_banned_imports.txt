# APIs that do not exist on Windows 7. FastSMRW targets Windows 7+, so none of
# these may appear in FastSMRW.exe's import table - a static import makes the
# app die at startup with "The procedure entry point X could not be located",
# before any of our code runs. Load such APIs with GetProcAddress instead.
#
# build.bat checks the linked exe against this list. Add a name here whenever
# a new toolset or SDK starts binding something newer.
#
# Lines starting with # are comments; one API name per line.
